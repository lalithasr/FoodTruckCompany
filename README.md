# FoodTruckCompany Backend

Spring Boot project scaffold with a layered package structure.

## Prerequisites

- JDK 21
- Maven 3.9+

## Project Structure

- `src/main/java/com/foodtruckcompany/config`
- `src/main/java/com/foodtruckcompany/controller`
- `src/main/java/com/foodtruckcompany/dto`
- `src/main/java/com/foodtruckcompany/entity`
- `src/main/java/com/foodtruckcompany/exception`
- `src/main/java/com/foodtruckcompany/repository`
- `src/main/java/com/foodtruckcompany/security`
- `src/main/java/com/foodtruckcompany/service`

## Run

```powershell
mvn spring-boot:run
```

## Test

```powershell
mvn test
```

## Sample Endpoint

- `GET /api/health`
- `GET /api/food-trucks`
